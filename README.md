# ER-CORE — Full Emergency Response & Coordination Website

This is the upgraded ER-CORE website package. It now opens as a **proper public website/landing page first**, with a polished emergency-response product presentation and a button that enters the interactive command center.

## Open the website
1. Extract this ZIP.
2. Open `frontend/index.html` in **Google Chrome, Microsoft Edge, or Firefox**.
3. You will first see the public ER-CORE website.
4. Click **Explore Command Center** / **Open ER-CORE Demo**.
5. Demo login:
   - Email: `dispatcher@ercore.demo`
   - Password: `demo123`

**Do not open `index.html` in WPS Office.** It is a web page and should be opened in a browser.

## Important
This is a **simulation/demo website**. The emergency data, maps, GPS movement, hospital capacity and AI recommendations are simulated. It is not connected to real emergency services.

## Backend starter
The `backend` folder contains a modular FastAPI starter with REST/WebSocket examples for future integration with PostgreSQL/PostGIS, real routing/traffic providers and ML services.
